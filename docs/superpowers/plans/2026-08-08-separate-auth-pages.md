# Separate auth pages Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Split `/login`'s sign-in/sign-up toggle into two real routes, `/login` and `/signup`, sharing form mechanics through one `AuthForm` component while each page owns its own copy and brand header, and add a client-side confirm-password field to sign-up.

**Architecture:** A shared `AuthForm` component (parameterized by `mode: "signin" | "signup"`) owns field rendering, validation, and submit; thin route files `src/routes/login.tsx` and `src/routes/signup.tsx` each render it plus their own headline/description and a new `AuthBrandHeader` lockup. `safeRedirect` is generalized to reject both auth paths as redirect targets.

**Tech Stack:** TanStack Router (file-based routes), `@tanstack/react-form`, better-auth (`src/lib/auth.ts`), Tailwind + shadcn/ui, Vitest.

## Global Constraints

- Route paths are exactly `/login` and `/signup` (lowercase, no dash) — `src/routes/login.tsx` and `src/routes/signup.tsx`.
- `safeRedirect()` in `src/lib/redirect.ts` must reject both `/login` and `/signup` as redirect targets (case-insensitive, trailing-slash tolerant), not just `/login`.
- The `_authed` guard (`src/routes/_authed.tsx`) keeps bouncing unauthenticated visitors to `/login` specifically — do not change its target to `/signup`.
- Layout stays the existing narrow, centered single column (`Page` with `max-w-sm`, vertically centered). No split-screen, no gradients, no illustrations — flat OKLCH amber-accent aesthetic plus the existing `.app-grain` texture, consistent with the rest of the app.
- Confirm-password is client-side only (a UX check against typos); better-auth's `signUp` still receives a single `password` value.
- No new component/form-rendering tests — this codebase's test coverage for auth is route-guard level (`src/routes/-routes.test.ts`) and utility level (`src/lib/redirect.test.ts`, `src/lib/credentials.test.ts`); match that, don't add a new category.
- `src/routeTree.gen.ts` is auto-generated by `deno task routes:generate` (`tsr generate`) — never hand-edit it.
- Typecheck/build: `deno task build`. Tests: `deno task test`.

/**
 * Sign-up only: catches a typo in the password before it round-trips to the
 * server as a hard-to-diagnose "wrong password" on the very next sign-in
 * attempt. Purely a client-side UX check — better-auth's signUp still takes
 * just the one password value.

export function validateConfirmPassword(
  password: string,
  confirmPassword: string,
): string | undefined {
  if (!confirmPassword) return "Confirm your password.";
  if (confirmPassword !== password) return "Passwords do not match.";
  return undefined;
}

- [ ] **Step 2: Create `src/components/auth-form.tsx`**

```tsx
import { useRouter } from "@tanstack/react-router";
import { useForm } from "@tanstack/react-form";
import { useState } from "react";
import { signIn, signUp } from "@/lib/auth";
import { safeRedirect } from "@/lib/redirect";
import {
  MIN_PASSWORD,
  validateConfirmPassword,
  validateEmail,
  validatePassword,
} from "@/lib/credentials";
import { Button } from "@/components/ui/button";
import { Input } from "@/components/ui/input";
import { Label } from "@/components/ui/label";
import { Alert, AlertDescription } from "@/components/ui/alert";

/** The first error, as a string — the meta array is typed wider than that. */
function firstError(errors: unknown[]): string | undefined {
  return typeof errors[0] === "string" ? errors[0] : undefined;
}

/**
 * The email/password (+ confirm, on sign-up) form shared by /login and
 * /signup. `mode` is fixed for the component's lifetime — each route mounts
 * its own instance — so, unlike the single-page toggle this replaced, no
 * effect has to re-run validation when the active password rule changes.
 */
export function AuthForm({
  mode,
  redirectTo,
}: {
  mode: "signin" | "signup";
  redirectTo: string | undefined;
}) {
  const router = useRouter();
  const [error, setError] = useState<string | null>(null);
  const isSignUp = mode === "signup";

  const form = useForm({
    defaultValues: { email: "", password: "", confirmPassword: "" },
    onSubmit: async ({ value }) => {
      setError(null);
      try {
        if (mode === "signin") await signIn(value.email, value.password);
        else await signUp(value.email, value.password);
        // signIn/signUp await a getSession() refresh before resolving, so
        // the store is already populated here and the _authed guard will
        // pass. `href` rather than `to` because the target is an arbitrary
        // runtime string, not a known route id.
        await router.navigate({ href: safeRedirect(redirectTo) });
      } catch (e) {
        setError(e instanceof Error ? e.message : "Sign in failed");
      }
    },
  });

  return (
    <form
      className="space-y-4"
      // The browser's own validation bubble would fire before ours and sit
      // outside the design; these fields report their own errors.
      noValidate
      onSubmit={(e) => {
        e.preventDefault();
        form.handleSubmit();
      }}
    >
      <form.Field
        name="email"
        validators={{ onChange: ({ value }) => validateEmail(value) }}
      >
        {(field) => {
          const message = field.state.meta.isTouched
            ? firstError(field.state.meta.errors)
            : undefined;

          return (
            <div className="space-y-2">
              <Label htmlFor={field.name}>Email</Label>
              <Input
                id={field.name}
                name={field.name}
                type="email"
                autoComplete="email"
                placeholder="you@example.com"
                aria-invalid={message ? true : undefined}
                aria-describedby={message ? `${field.name}-error` : undefined}
                value={field.state.value}
                onBlur={field.handleBlur}
                onChange={(e) => field.handleChange(e.target.value)}
              />
              {message && (
                <p id={`${field.name}-error`} className="text-sm text-destructive">
                  {message}
                </p>
              )}
            </div>
          );
        }}
      </form.Field>

      <form.Field
        name="password"
        validators={{
          onChange: ({ value }) => validatePassword(value, { isSignUp }),
        }}
      >
        {(field) => {
          const message = field.state.meta.isTouched
            ? firstError(field.state.meta.errors)
            : undefined;

          return (
            <div className="space-y-2">
              <Label htmlFor={field.name}>Password</Label>
              <Input
                id={field.name}
                name={field.name}
                type="password"
                autoComplete={isSignUp ? "new-password" : "current-password"}
                aria-invalid={message ? true : undefined}
                aria-describedby={
                  message
                    ? `${field.name}-error`
                    : isSignUp
                      ? `${field.name}-hint`
                      : undefined
                }
                value={field.state.value}
                onBlur={field.handleBlur}
                onChange={(e) => field.handleChange(e.target.value)}
              />
              {message ? (
                <p id={`${field.name}-error`} className="text-sm text-destructive">
                  {message}
                </p>
              ) : (
                isSignUp && (
                  <p id={`${field.name}-hint`} className="text-sm text-muted-foreground">
                    At least {MIN_PASSWORD} characters.
                  </p>
                )
              )}
            </div>
          );
        }}
      </form.Field>

      {isSignUp && (
        <form.Field
          name="confirmPassword"
          validators={{
            onChange: ({ value, fieldApi }) =>
              validateConfirmPassword(
                fieldApi.form.getFieldValue("password"),
                value,
              ),
            onChangeListenTo: ["password"],
          }}
        >
          {(field) => {
            const message = field.state.meta.isTouched
              ? firstError(field.state.meta.errors)
              : undefined;

            return (
              <div className="space-y-2">
                <Label htmlFor={field.name}>Confirm password</Label>
                <Input
                  id={field.name}
                  name={field.name}
                  type="password"
                  autoComplete="new-password"
                  aria-invalid={message ? true : undefined}
                  aria-describedby={message ? `${field.name}-error` : undefined}
                  value={field.state.value}
                  onBlur={field.handleBlur}
                  onChange={(e) => field.handleChange(e.target.value)}
                />
                {message && (
                  <p id={`${field.name}-error`} className="text-sm text-destructive">
                    {message}
                  </p>
                )}
              </div>
            );
          }}
        </form.Field>
      )}

      {error && (
        <Alert variant="destructive">
          <AlertDescription>{error}</AlertDescription>
        </Alert>
      )}

      <form.Subscribe
        selector={(state) => [state.canSubmit, state.isSubmitting] as const}
      >
        {([canSubmit, isSubmitting]) => (
          <Button
            type="submit"
            size="lg"
            className="w-full"
            disabled={!canSubmit || isSubmitting}
          >
            {isSubmitting
              ? isSignUp
                ? "Creating account…"
                : "Signing in…"
              : isSignUp
                ? "Create account"
                : "Sign in"}
          </Button>
        )}
      </form.Subscribe>
    </form>
  );
}
```
